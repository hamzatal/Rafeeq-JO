## قواعد هذه الوثائق

| القاعدة | السبب |
|---|---|
| **`ROADMAP.md` هو المصدر الوحيد للحقيقة** | خطّتان تعنيان صفر خطّة |
| **`SCHEMA.generated.md` لا يُعدَّل يدوياً** | مولَّد من قاعدة حيّة — التعديل اليدوي يُمحى ويكذب |

| **ما لم يُتحقَّق منه مُعلَّم صريحاً** | `AUDIT.md` §9 و`JORDAN-COMPLIANCE.md` تُعلّم كل استنتاج: متحقَّق · قراءة · للمحامي |
