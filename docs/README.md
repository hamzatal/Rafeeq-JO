## القواعد

1. **فرع واحد `main`.** كل عمل في `feat/`·`fix/`·`chore/`·`docs/` وينتهي بـPR وحذف تلقائي.
2. **رقم Issue هو المعرّف.** لا `RFQ-###` جديد — RFQ‑366 كان الأخير.
3. **CI أخضر إلزامي للدمج.** بلا استثناء، بلا `--no-verify`.
4. **رسائل الكوميت:** `type(scope): subject` بالإنجليزية.
5. **كل إصلاح مالي أو أمني يحتاج اختباراً يفشل قبله وينجح بعده.**
6. **الحذف قبل الإضافة** — أي ميزة جديدة تحتاج مبرّراً مكتوباً في Issue.

## بنية المشروع

```
backend/            Laravel 12 · PHP 8.4 · معماري modular
  Core/             أساسيات مشتركة (تدقيق · صلاحيات · استجابات · استثناءات)
  Infrastructure/   المزوّدون الخارجيون (GPT · خرائط · إشعارات · SMS)
  Modules/          شرائح رأسية — كل موديول له Routes/Controllers/Services/Models
frontend/
  student-app/      Expo · React Native
  driver-app/       Expo · React Native
  admin-dashboard/  Next.js 14
  packages/
    shared/         الأنواع · i18n · الثوابت
    api-client/     طبقة HTTP موحّدة
docs/               هذه الوثائق
deployment/         compose الإنتاج
```

> **ملاحظة:** بنية `packages/` ستتوسّع في المرحلتين 6 و7 بـ`tokens` و`ui` — لأن اليوم يوجد **962 سطر مكوّنات مكرّرة حرفياً** بين تطبيقي الموبايل.
