## الإجراءات

1. **موافقة صريحة (consent)** قبل إرسال أي إيصال إلى OpenAI + **تنقيح أرقام الحسابات** قبل الإرسال + **إفصاح OpenAI كمعالج فرعي** في سياسة الخصوصية + استبدل `temporaryUrl` بتمرير `base64` فقط (لا روابط عامة).
2. **`PruneDriverLocations`** (7 أيام) + إصلاح `PruneTripTracking` ليشمل الرحلات العالقة.
3. **`PruneDriverDocuments`** — حذف الملفات بعد الرفض النهائي/الاستقالة + ربطها بـ `deleteAccount`.
4. **`anonymizeAccount()`** — استبدال الاسم/الهاتف/البريد بقيم مُجهَّلة، وحذف الوثائق، مع الإبقاء على السجل المالي المُجهَّل.
5. **`encrypted` casts** على الهاتف والاسم والعناوين (يتطلّب migration + فهرس hash للبحث بالهاتف).
6. **نسخ احتياطي:** `pg_dump` يومي + تخزين خارج الموقع + **اختبار استعادة مؤتمَت شهرياً** + healthcheck على `scheduler`.
7. **راجع المستندات القانونية الأربعة** لتطابق الكود بالحرف.
