# مصادر الهوية — قابلة لإعادة التوليد

الصفائح في `../v2/` **ليست صوراً ميتة** — هي ناتج هذا الكود.

```bash
cd docs/design/src
npm i -D playwright && npx playwright install chromium
# صفائح المراجعة الكاملة → ../v2/
for g in gen-student gen-money gen-driver gen-admin gen-extra; do node $g.mjs; done
node shoot.mjs             # كل الصفائح
node shoot.mjs 05-driver   # صفيحة واحدة

# أصول الـREADME → ../readme/
node gen-readme.mjs && node shoot-readme.mjs
node gen-icons.mjs         # أيقونات شبكة المزايا → ../readme/icons/
```

| الملف | الدور |
|---|---|
| `kit.css` | **التوكنز**. كل لون ومقاس ومسافة. تغيير اللون هنا يغيّر كل الصفائح. |
| `ui.mjs` | مكتبة المكوّنات: أيقونات Lucide · شريط الحالة · التبويب · البطاقات · الصفوف · الخريطة |
| `admin.mjs` | قوالب لوحة الإدارة: الهيكل · الجداول · KPIs |
| `gen-{student,money,driver,admin,extra}.mjs` | تعريف الشاشات كبيانات → صفائح `../v2/` |
| `gen-readme.mjs` | أصول الـREADME: البانر · الشعار · اللوحة · شرائح العرض → `../readme/` |
| `gen-icons.mjs` | أيقونات Lucide مفردة بلون العلامة → `../readme/icons/` (PNG لا SVG لضمان العرض على GitHub) |
| `shoot.mjs` · `shoot-readme.mjs` | يصوّران بـ Playwright · **يفشلان** إن تجاوزت صورة 8000px |

**تبديل لون العلامة:** عدّل `--b50…--b900` في `kit.css` وأعد التشغيل. النظام مستقل عن اللون.

## مصائد تعلَّمناها بالتجربة

| المصيدة | القاعدة |
|---|---|
| **لا خطّ إيموجي في المصيِّر** | `✓ ⏳ ● ⚠ ★ × → −` تُرسم مربّعات فارغة. استخدم SVG داخلياً أو أصناف `.i-*` في `kit.css`. |
| **`unicode-bidi:isolate` وحده لا يكفي** | لا بدّ من `direction:ltr` معه على الأرقام، وإلّا انقلب `-1.050` إلى `1.050-` و`34 / 40` إلى `40 / 34`. |
| **`د.أ` داخل عنصر `.num`** | `.num` تفرض LTR فيسبق الرقمُ العملةَ — وهو مقلوب عربياً. اعزل الأرقام وحدها: `<span class="num">142.500</span> د.أ`. |
| **`inset-inline-*` مع `left/top` في القالب نفسه** | في RTL يصبح `inset-inline-end` هو الحدّ الأيسر فعلياً. خلطهما دفن نصّ البانر تحت الهواتف. استخدم عائلة واحدة. |
| **`.bs` بارتفاع ثابت** | الشيت السفلي بارتفاع مُعطى يترك شريطاً أبيض ميتاً تحت آخر عنصر. أعطه `bottom:` فقط وليحتضن محتواه. |
| **حدّ 8000px** | أي بُعد يتجاوزه يتعذّر عرضه. `shoot*.mjs` يفشل عمداً حينها — قسّم الصفيحة. |
| **ارتفاع الـviewport يُلوَّث في `fullPage`** | اجعله صغيراً (80px) وإلّا حُشيت الصورة إلى ارتفاع الـviewport بأبيض. |
