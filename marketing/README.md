# مجلّد التسويق — منشورات جاهزة للنشر

**26 صورة بمقاساتها الصحيحة + 20 نصّ منشور جاهز.** كل صورة معها ملفّ `.txt` بنفس الاسم
يحتوي التعليق والوسوم — انسخ والصق وانشر.

```
marketing/
├─ README.md          ← هذا الملف: الفهرس وقواعد الاستخدام
├─ STRATEGY.md        ← الاستراتيجية: الموضع · التقويم · الإعلانات · الأرقام
└─ posts/             ← 26 صورة + 20 نصّاً
```

> **كل شيء هنا مولَّد من نظام التصميم** بـ`docs/design/src/gen-marketing.mjs`. فتغيير لون
> العلامة أو الشِعار يُعاد توليد المنشورات كلّها منه — ولا يوجد أصل بصري «يدوي» ينحرف عن الهوية.

## قواعد الاستخدام

| القاعدة | السبب |
|---|---|
| **الأسعار تُطابق [`../docs/product/PRICING.md`](../docs/product/PRICING.md) والتعرفة المُقرَّة** | نشر سعر غير مُقرّ **مخالفة تنظيمية** لا خطأ تسويقي |
| **لا تصنع أصلاً بصرياً خارج نظام التصميم** | أي لون أو خطّ من خارجه **يُضعف** العلامة بدل أن يبنيها |
| **لا تنشر صورة شخص بلا موافقة مكتوبة** | بلا استثناء — كابتناً كان أو طالباً |
| **ثلاث منازل عشرية دائماً** | `1.500 د.أ` لا `1.5` — الدينار = 1000 فلس |
| **لا تحذف تعليقاً سلبياً** إلّا إن كان مسيئاً أو يكشف بيانات | الحذف يصنع لقطة شاشة، واللقطة تنتشر أكثر من التعليق |
| **قِس تكلفة أول رحلة لا تكلفة التنزيل** | من ينزّل ولا يطلب لا يساوي شيئاً |

## إعادة التوليد

```bash
cd docs/design/src
npm i -D playwright && npx playwright install chromium
node gen-marketing.mjs        # → ../../../marketing/posts/
```

**لتغيير رقم أو نصّ:** عدّل `gen-marketing.mjs` وأعِد التشغيل. **لا تُعدّل الصور مباشرة** —
